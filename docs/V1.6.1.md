# Odin III 1.6.1 release notes

Status: ready to tag (`v1.6.1`; the tag is the owner's). Built from `origin/main` `de832ecb` plus the release PR.

## What it is

A patch release on v1.6.0. The C ABI stays 7: `include/odin3/odin3.h` has no change since v1.6.0 except the version
macros. Purpose: Odin III goal 1 (VTR-comparable results) and the AI-digit and NeuraLUT corpora, which hit gaps in the
front end, the Quartus (LPM) output leg and the simulator. Twelve PRs since v1.6.0, each a squash merge on `main`.

## Front end

- A variable index into every dimension of a multi-dimensional register or net array is a nested case over the words
  (#418); a function or task may declare a local array (#418).
- A module elaborated by an earlier `read_verilog` can be instantiated by a later one; a `#()` override of it is an
  error that says to read it with `--lib` (#420).
- `read_verilog -D NAME[=VALUE]` and `-I DIR`, repeatable, after the project record's (#422).
- `odin3-flow --project X.o3proj`: the project declares files, include directories, defines and top (#426).

## Quartus (LPM) leg

- `write_verilog --quartus [--sim-file F]` and `odin3-flow --target lpm` write a netlist with no Odin-internal cell and
  no library module definition; the stubs go to `<top>_lpm_sim.v` (#419). Power-up values of word flip-flops are written
  as `initial` (#423).
- A ROM (one read port, no write port, every `INIT` bit defined, synchronous rising-edge read, no read enable) maps to
  `altsyncram` `operation_mode "ROM"`; `write_verilog` writes `<netlist>_rom<N>.mif` and names it in `init_file`
  (#429). AI-digit I3 P=1: altsyncram 5 to 10, behavioural reg arrays 5 to 0, netlist 2.73 MB to 419 KB. The VTR leg is
  unchanged. A RAM with `INIT`, an asynchronous or falling-edge ROM read, a read enable or unknown `INIT` bits stays soft
  with a warning.

## Simulator and ABC

- `lower --keep-mem-cells` leaves each `$mem` as a cell and `sim_tb` / `sim` model it directly; the AI-digit layer
  `l_fc2` unit test (30,395 cycles) runs 13 times faster than through `lower` (#428, design in #425).
- `sim_tb` accepts a DUT `#()` whose values equal the module defaults (#427).
- `abc` charges the ANDs of a gate's irredundant cover (AND/OR 1, XOR 3, inverter 0) in its pre-run memory estimate; the
  NeuraLUT designs nl-A and nl-C no longer hit the 4 GiB budget (#424).

## Known limits

- Quartus acceptance of the ROM instance (and of the netlists above) is untested: no Quartus is available to the project,
  and the repo has no LPM simulation models, so the ROM check is the `.mif` against the expected words.
- `$mem` with several clocks, or an asynchronous write port, is refused by the simulator's cell model (a located error).
- `read_verilog -P` (parameter override on the command line) does not exist yet; `sim_tb` says so.
- Netlist-view passes still need the default `lower` (not `--keep-mem-cells`).

## Upgrade notes

No flag was removed and no output changed for existing flows, except: `lib/lpm.o3lib` declares `init_file` on
`altsyncram` (printed as the last parameter of every `altsyncram` instance), and a Verilog netlist from an implicit black
box keeps its overrides as `parameter:<NAME>` node attributes.
