# Odin III 1.5.0 release notes

Status: ready to tag (`v1.5.0`; the tag is the owner's). Built from `origin/main` `109b1b6a` plus the release PR.

## What it is

v1.5.0 is a minor release on v1.4.0. The C ABI stays 7: the header adds functions, none changes or goes
(see Upgrade notes). Purpose: Odin III S1 (simulation parity with iverilog, so Bifrost III and the Mimir
benchmarks can use the simulator) and O1/O2 (VTR-comparable flow, provenance back to the HDL). 74 commits
since v1.4.0 (PR numbers below; each is a squash merge on `main`).

### 2. `--vcd-all`
`sim` and `sim_tb --vcd F --vcd-all [--vcd-names short|provenance|hash]` dump one 1-bit variable per connected
net under the name `write_blif --vtr` gives it, so a waveform joins the VTR netlist and its provenance:
#391 (`d60a4bb5`). Used by the Bifrost P1 check on mmuart (284 matched nets, P1 difference at most 1.24e-4 over
known time).

## Compatibility and upgrade notes

- C ABI stays 7. New public functions (additive, in `include/odin3/odin3.h`): `odin3_graphlets_instances`,
  `odin3_graphlet_nodes`, `odin3_graphlets_similarity` (#390). The simulator functions `odin3_sim_poke_state`,
  `odin3_sim_signals_poke` (#398), `odin3_sim_{set_input4,get_input4,get_output4,is_four_state}` and the option
  `odin3_sim_options.four_state` (#382), and `odin3_blif_names_net` (#391) are internal (declared in `src/sim/` and
  `src/backends/blif/`), used by `sim_tb`; they are not public ABI.
  A consumer built against 1.4.0 keeps working.
- Behaviour change: `sim_tb` is 4-state by default (#392). A testbench that relied on x being 0 reads x until
  reset. `--2state` restores the old interpreter. The project runner (`run_testbenches`) stays 2-state.
- `proc` sets the node attribute `odin3 rtl_sel` (hidden from RTLIL, JSON and Verilog writers).
- `lower --async keep` cells are refused by `write_blif` (documented in `docs/user/flow.md`); `write_json`
  accepts them.
- `tristate` runs after `flatten` in `odin3-flow`; `--strict-tristate` keeps the old error.
- Pins: Wyrd/Bifrost, Heimdall, Mimir and Leman Russ can pin `odin3 1.5.0` (`pyproject.toml`).

## Known gaps

- `real`, fork/join, events, `disable`, `defparam` onto DUT instances, `@*`, `specify` in testbenches
  (table above). DUT-side tri-state in `sim_tb` (a `$tribuf` has no model before `lower`).
- Shifts, divide, modulo and power have no word-level simulation hooks; after `lower` they are gate level, so an
  x shift amount gives merge-like results, not IEEE all-x.
- `repeat (x)` runs zero iterations (IEEE); iverilog 12 loops forever.
- `opt_merge` can merge an if-mux with an identical `?:` mux; the merged cell loses the `rtl_sel` mark.
- The silicon flow: limits of 1.4.0 stand (`docs/user/silicon-flow.md`); wb_lcd equivalence stays not proven (#355).
