# D8: Core in C++20 (v0.1)

Status: Superseded by D8' (see D8-prime.md)
Date: 2026-10-08 (spec date; the v0.1 decision date is not recorded in the spec)

This record is deliberately thin. The v0.2 spec keeps only a pointer to the v0.1 decision;
nothing else about it survives in docs/DESIGN.md.

## Context
Not stated in the spec. The v0.1 rationale for choosing C++20 is not recorded in v0.2 and is
not reconstructed here. (Peter: add it if you remember it.)

## Decision
The core was to be written in C++20. This is all the spec says: D8' "Supersedes the C++20
choice in v0.1" (spec §2), and the preamble says v0.2 changed the language to structured C.
Whatever else v0.1 said about D8 (platform, toolchain, build) is not in the v0.2 spec.
Platform, CMake, CI, and the Claude Code/architect roles are restated under D8'.

## Consequences
Not recorded for the original decision. For the replacement, see D8'. What the supersession
shows (from spec §2, D8' rationale) is that the following were judged to favour C:
agent authorship and human review simplicity, a stable plugin boundary, libabc being C, the
Odin II lineage, and lint-enforceable complexity.
