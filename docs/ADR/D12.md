# D12: Drop the CIRCT writer from v1.0; Phase 7 is release

Status: Accepted
Date: 2026-10-21

## Context
D7 promised `write_circt` (hw/comb/seq) as an interop path. By Phase 7 Odin III writes BLIF
(plain and VTR), Verilog (word, gate, LUT, LPM), Yosys JSON (plus `--odin3`) and dot, and reads
BLIF, Verilog and JSON back. No user of a CIRCT output is in sight, and no CIRCT tools are
installed to test one (Phase 7 brainstorm, 2026-10-21).

## Decision
Peter, 2026-10-21: drop the CIRCT writer (7.1) from v1.0 ("We have outputs, so probably this is
nothing and we can drop it"). Phase 7 is polish, user documentation, a flow script that takes a
basic design through, the core support the reverse-engineering tool needs (`submod`, design copy,
`cone_check`, `raise`), and the release (source and pip package). No API stability promise for
v1.0. Spec: `docs/specs/2026-10-21-7-release-design.md`.

## Consequences
Positive:
- v1.0 is reachable without an MLIR/LLVM toolchain.
- The release effort goes to usability (docs, flow script) and the RE research use.
Negative:
- No CIRCT interop; a plugin can add `write_circt` later.
Forces on later phases:
- After v1.0: benchmark runner, Python GUI, RTL viewer, Verilog Town (Pygame CE), and the RE tool
  (`docs/RE-ARCHITECTURE.md`), each with its own spec.
