# D6: Altera primitives are first-class

Status: Accepted
Date: 2026-10-08

## Context
LPM instances are pre-bound hard blocks, and Titan is in scope early (spec §2 rationale).
Altera primitives include LPM, `alt*`, and `stratixiv_*`/`cycloneiv_*`.

## Decision
Altera primitives are first-class. A primitive library elaborates them to generic cells.
`unbind`/`bind` passes move between generic and target-bound forms.

## Consequences
Positive:
- VQM is read with the Verilog grammar plus the primitive library, no new parser (spec §4.4).
- The primitive library supplies the Altera hard set for partial mapping (spec §5.2, §6 step 7).
Negative:
- A primitive library must be authored and kept faithful to Quartus semantics; its scope is
  open (spec §13 #3).
Forces on later phases:
- Phase 2: primitive library v0; smallest Titan design parsed (spec §12).
- Phase 6: VQM/EDIF readers, Altera `bind` output, Titan subset.
- Spec §9: Verilog writer has an Altera-primitive flavour (the RE output).

## Related
- D1 (hard cells), D2 (VQM through the Verilog grammar), D5 (explicit-instantiation tier of
  inference, spec §7).
- Spec §4.4, §6, §7, §9, §11 (Titan).
- Open questions touched: §13 #3 (primitive library v0 scope), §13 #5 (which Altera generation
  for `bind` output first).

Revisit if: the smallest Titan designs need primitives outside the chosen v0 set in a way that
breaks the "elaborate to generic cells" model, or `unbind`/`bind` cannot round-trip.
