# D11: v1.0 phase plan (2026-10-19)

Status: Accepted
Date: 2026-10-19

## Context
D10 re-scoped v1.0, and its follow-up 2 recorded Peter's three goals for Odin III: (1) Verilog
through the modern VTR flow with results comparable to Parmys; (2) a platform for netlist
analysis and reverse engineering; (3) provenance from the final netlist back to the HDL. It
then added FSM (4.8), the LPM path (4.14) and the analysis flow (4.15 to 4.19) to Phase 4,
which made Phase 4 too large for one phase, while the old Phases 5 (SystemVerilog/VHDL) and 6
(`raise`, VQM, Titan) were already out of v1.0.

Peter, 2026-10-19, on the proposed split: "yes to all recommendations". On Phase 5: "I would
argue is just an output path that's pretty simple since it's just outputting Verilog - so our
outputs our JSON, BLIF, and Verilog (at different levels) - the LPM outpath I don't think we
need to test it heavily until I need that step so it's a simpler output form ... An
additional question is for each of these outputs we need to be able to read it." Then: "yes
to all recommendations".

## Decision
The v1.0 phases are:

| Phase | Name | Plan |
|---|---|---|
| 0 | Setup (done) | `docs/PHASE0.md` |
| 1 | Core IR, BLIF, writers, simulator (done) | `docs/PHASE1.md` |
| 2 | Verilog front end, project, `proc`, `opt` (done) | `docs/PHASE2.md` |
| 3 | VTR flow (`flatten`, `wreduce`, `hardmap`, `lower`, linked ABC, `write_blif --vtr`, `vtr-qor`) | `docs/PHASE3.md` |
| 4 | VTR architectures and FSM: 4.1 to 4.8, 4.13 | `docs/PHASE4.md` |
| 5 | Outputs and read-back: 5.1 LPM (light), 5.2 Verilog read-back at every level (`read_verilog -icells`), 5.3 Yosys JSON reader, 5.4 HDL locations through write and read | `docs/PHASE5.md` |
| 6 | Analysis flow and provenance: 6.1 gate-level netlist ingest, 6.2 `write_dot --color-by`, 6.3 graph export (Yosys JSON plus Odin III keys), 6.4 `levelize`, 6.5 provenance coverage gate | `docs/PHASE6.md` |
| 7 | Release: 7.1 CIRCT writer, 7.3 visual tooling polish, 7.4 docs and extension-API review, 7.6 packaging and the v1.0 tag | DESIGN §12 |

- **Moved items.** PHASE4 4.14 becomes 5.1; 4.15 to 4.19 become 6.1 to 6.5; 7.2 (Yosys JSON
  reader) becomes 5.3; 7.5 (EDIF writer) stays dropped (D10).
- **Read-back.** BLIF, Verilog and JSON outputs must read back into Odin III with their HDL
  locations. dot (view only) and RTLIL (Yosys interop) need no reader.
- **LPM is light.** Tested by write, read back and lint; equivalence under LPM models and a
  Quartus compile wait until Peter needs that step. It starts when a Phase 3 lane frees up.
- **Graph export** is Yosys JSON plus versioned Odin III keys, read by the 5.3 reader.
- **After v1.0** (not phases of v1.0): the research plugins of D10 follow-up 2 (Gate-Breaker
  redo, Bayesian classifier, graphlets, graph sandwich, GNNs, placement study); SystemVerilog
  via slang and VHDL via GHDL (the old Phase 5); and the matcher, `raise`, VQM/EDIF, device
  atoms and Titan (the old Phase 6). Their designs stay in DESIGN §12.1. Older documents that
  say "Phase 5" for slang/GHDL or "Phase 6" for `raise`/VQM mean these post-v1.0 items.
- **Order.** Phase 3 finishes first (lanes stay on it until M3). Phase 5's 5.1 starts when a
  lane frees up; then one lane each on Phases 4, 5 and 6; Phase 7 last.

Supersedes D10's phase numbering (its "Phase 5 deferred, Phase 6 removed" and its Phase 4 item
list). D10's scope decisions stand.

## Consequences
Positive:
- Phases match the goals: 3 and 4 serve goal 1, 5 and 6 serve goals 2 and 3.
- Every output Odin III writes can be read back, so analysis can start from any level.
- Phases 4, 5 and 6 are independent enough to run as three lanes.
Negative:
- More work than D10's Phase 4 alone (read-back, JSON reader moved earlier): v1.0 about
  Nov 12-17 instead of Nov 10-15.
- Older docs use the old numbers for slang/GHDL and `raise`; D11 is the key.
Forces on later phases:
- `read_verilog` gains `-icells`; `read_blif` and `read_verilog` gain provenance read-back;
  the Verilog writer gains `src` attributes.
- IR provenance, IDs and hierarchy stay intact (D9, D10).
