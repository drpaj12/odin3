# Hypothesis register: the Odin III paper (odin3.tex, Part I results and Part II measured results)

Step 1 of the restructure (brief `papers-hypothesis-register.md`, 2026-10-28). Register only: the .tex is untouched, no new experiment, every number is copied from a committed file named in the row. Branched from origin/docs/paper-tree head `5737610e` because odin3 #295 is still open (the paper on origin/main is older).

Verdict words: USEFUL = supported under the stated gate or check; DISMISSED = failed; INCONCLUSIVE = neither or only partly shown (limit stated). Never upgraded beyond the committed numbers.
Framing: PRE-REGISTERED = the rule is a dated decision or spec text committed before the run (cited with the git blame time); RECONSTRUCTED = built from the claim the paper makes and the check it cites, never presented as pre-registered. Odin III is a systems paper: most rows are acceptance gates and checks, not statistical tests; there is no p-value anywhere, and the table says "gate", "count" or "none" in the test column.
Measures: area = LUTs, CLBs, minimum channel width (W); speed = critical-path delay (CPD) and routed wirelength (WL); power is never measured; near-critical statistics: none in the paper (v1.1.1 reports the critical path and the paths within a window as a tool feature, not as an experiment). Designs: the 15 VTR designs that fit the development laptop (largest five shipped out, untested here), VTR commit 3c9a4d23, k6_frac_N10_frac_chain_mem32K_40nm.

Source keys: `P3` = docs/PHASE3.md, `P4` = docs/PHASE4.md, `V120` = docs/V1.2.0.md, `V111` = docs/V1.1.1.md; paper lines are odin3.tex at `5737610e`.
