# 5.2 `read_verilog -icells` (Verilog read-back at every level) Implementation Plan (v1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox
> (`- [x]`) syntax. Commit and push after every task (PHASE5, "commit incrementally").

v1 (2026-10-20). Spec: `docs/specs/2026-10-20-5.2-icells-design.md` v1 (rule IDs I, N, V, X, T are
binding). The spec's twelve questions are taken as **agent defaults** (PHASE5 decision 9, logged by
Task 6); this is not a mapping algorithm and changes no IR, ABI, ADR or the elaboration of Verilog
without `-icells`, so the controller approves the plan. **Stop and report** if a task finds it
needs an IR or invariant change, an ABI change, an ADR or design-rule change, or a change to how
Verilog without `-icells` elaborates.

**Goal:** `read_verilog -icells` reads an instance of a registered `$` cell type as that cell,
with parameters from `#(...)` and ports by name, validated against the registry; and a tool proves,
on the micros, that the Verilog written at the word, gate, LUT and LPM levels reads back
equivalent.

**Architecture:** one new first step in EL-6 resolution (`elab1_lookup.c`), an option in
`odin3_elab_opts`, three small stage 1/2 changes for the checks of spec §4, a Python tool
`tools/icells-check` over `opt_equiv.Checker`, level scripts and a curated list in `tests/icells/`.

**Branch:** `feat/5.2-icells` (from `feat/5.1-lpm-spec` at 12412bb7). When PR #154 is MERGED
(`gh pr view 154 -R drpaj12/odin3 --json state`), `git merge origin/main` (merge only). No PR from
the lane; the controller reviews.

**Build and test:** `cmake --preset debug`; `/home/jamiespa/odin3-ws/work/controller-scripts/build-mem.sh
--preset debug`; `env -u ODIN3_HEAVY_OK ctest --preset debug -R <targeted> -j6`; full debug ctest
and full `tools/lint.sh` before the last push. Nothing runs under `tools/heavy-run`.
