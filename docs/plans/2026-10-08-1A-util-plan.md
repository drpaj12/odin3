# 1A `src/util/` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Odin III's only generic containers (alloc wrapper, arena, vec, pagevec, hash, u64map, idindex, str, log) as tested C17, and move the build to an object library with a hidden-visibility `libodin3.so`.

**Architecture:** `src/util/*.c` plus `src/api/*.c` form the CMake object library `odin3_core`; `libodin3.so` is linked from it with `-fvisibility=hidden`, exporting only `odin3.h` functions. Unit tests link `odin3_core` directly. Every container allocates through one wrapper with a test-only failure hook.

**Tech Stack:** C17, CMake ≥ 3.25 presets (`debug` = ASan+UBSan), Unity (`third_party/unity`), clang-tidy/cppcheck/lizard via `tools/lint.sh`.

**Spec:** `docs/specs/2026-10-08-1A-util-design.md` (approved 2026-10-08). Read it before any task; it holds every public signature. This plan does not repeat them.

## Global Constraints

- C17 with `-Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wstrict-prototypes -Wmissing-prototypes -Wvla -Werror`.
- Functions: cyclomatic complexity ≤ 15, ≤ 60 lines, ≤ 5 parameters; no two adjacent parameters of convertible types (`bugprone-easily-swappable-parameters`).
- No `abort()`/`exit()`/`goto` (except `cleanup:`), no VLAs, no recursion. Never add `NOLINT` or relax `.clang-tidy`.
- Names: `odin3_` prefix, snake_case; one-letter names only `i`, `j`, `k`.
- Out of memory and 32-bit ID exhaustion → `ODIN3_ERR_NO_MEMORY` or the documented `NULL`/`false`; never a crash.
- Hash seed is the fixed constant `ODIN3_HASH_SEED = 0x6f64696e33`; no randomness anywhere.
- All `util` heap allocation goes through `odin3_util_malloc/calloc/realloc/free`.
- Every file starts with the project's header comment style (`/* file.c — one line on what it is. */`).
- Before each commit: `tools/lint.sh` passes (the pre-commit hook runs it without clang-tidy; run the full gate yourself before the last commit of each task: `tools/lint.sh`).
- Build/test command used throughout: `cmake --preset debug && cmake --build --preset debug && ctest --preset debug --output-on-failure`.

## Review Focus

1. A string longer than the arena chunk (e.g. 100 KiB) is interned and read back intact — test in Task 7.
2. A log sink that itself calls `odin3_log` must not recurse forever: the nested call is dropped (counted, not delivered) — test in Task 8.
3. `odin3_strbuf_append` with `{NULL, 0}` is a successful no-op, and `data` is NUL-terminated after every successful append — test in Task 7.
4. `odin3_u64map_next` / iteration on an empty map returns `false` immediately — test in Task 5.
5. `odin3_arena_create(1)` (chunk smaller than `max_align_t`) still returns correctly aligned memory — test in Task 3.

### Task 2: Hashing

**Files:** Create `src/util/hash.h`, `src/util/hash.c`, `tests/unit/test_util_hash.c`

**Interfaces:**
- Produces: `odin3_bytes`, `odin3_hash_bytes(odin3_bytes, uint64_t seed)`, `odin3_hash_u64(uint64_t)`, `ODIN3_HASH_SEED`, plus `odin3_bytes odin3_bytes_cstr(const char *s)` (pointer + `strlen`).

- [ ] **Step 1: Tests with exact vectors** (algorithm: `h = 0xcbf29ce484222325 ^ seed`; per byte `h ^= b; h *= 0x100000001b3`; return `fmix64(h)`; `fmix64(k)`: `k ^= k>>33; k *= 0xff51afd7ed558ccd; k ^= k>>33; k *= 0xc4ceb9fe1a85ec53; k ^= k>>33`):
  - `hash_bytes("", ODIN3_HASH_SEED) == 0xdf2d2a779b7e2325`
  - `hash_bytes("a", ODIN3_HASH_SEED) == 0xcecb8d4d295357fa`
  - `hash_bytes("odin3", ODIN3_HASH_SEED) == 0x952238a8a1375f22`
  - `hash_bytes("odin3", 0) == 0xe77a0e3cbf70455e`
  - `hash_u64(1) == 0xb456bcfc34c2cb2c`, `hash_u64(0) == 0`
  - `hash_bytes({NULL, 0}, s) == hash_bytes("", s)`
- [ ] **Step 2: Build; expect compile failure. Step 3: implement. Step 4: tests pass. Step 5: lint; commit** `util: FNV-1a/fmix64 hashing`.
