# 1E Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cycle-based 2-state netlist simulator using op-registry `simulate` hooks, and the Phase 1 exit test "sim matches the reference on the goldens" (PHASE1 #13).

**Architecture:** `odin3_sim_build` flattens a module's hierarchy into a flat program (bit-indexed value array, cell list, state list), levelizes combinational cells once (iterative topological sort; latches cut the graph), and each cycle drives inputs, settles, applies rising then falling clock edges, settles, and samples outputs. Cell semantics are per-type hooks; tech-library hard cells interpret their `fn` ASTs.

**Tech Stack:** C17, `src/util`, `src/ir`, `src/techlib` (1G), `src/frontends/blif` (1C), Icarus Verilog, ABC, Yosys (references), bash.

**Spec:** `docs/specs/2026-10-09-1E-sim-design.md`; PHASE1 #13; IR.md IR-8 (simulate hook).

**Ordering:** starts after 1C merges (Tasks 1–3, 5 need the BLIF reader); Task 4 needs 1G merged.

## Global Constraints

- All earlier constraints (C17 `-Werror`, function limits, no adjacent convertible params, no abort/exit/goto/VLA/recursion, no NOLINT, `odin3_` snake_case, util-only containers, IR via API, deterministic, located errors).
- Simulation is deterministic for a seed (PRNG: a fixed xorshift64* in `src/sim`, no libc `rand`).
- Linear build time and memory in netlist size; per-cycle time linear in cells.

## Review Focus

1. A `$_DFF_N_` and a `$_DFF_P_` on the same clock update on opposite edges within one cycle — test in Task 3.
2. A combinational loop is rejected naming a net on the loop — test in Task 2.
3. `$sop` with an OFF-set cover (rows ending `0`) evaluates as the complement — test in Task 1.
4. A design whose latch clock is driven by logic (not a primary input) is rejected with a message — test in Task 2.
5. A multiply wider than 64 bits per operand (golden `multiply` is 36×36 → 72-bit output) is exact — test in Task 4.

### Task 1: Simulate hook contract and bit-level semantics
**Files:** Modify `src/ir/celltype.h` (the `simulate` hook: `void (*simulate)(const odin3_sim_cell *cell)` where `odin3_sim_cell` exposes per-port input/output bit spans in the simulator's value array, the node's parameters, and (sequential types) a state span plus an event kind: `ODIN3_SIM_COMB`, `ODIN3_SIM_POSEDGE`, `ODIN3_SIM_NEGEDGE`; a flag marking sequential types), `src/ir/cells/{gates,const,sop,dff}.c` (hooks); Create `src/sim/cell.h` (the `odin3_sim_cell` view), `tests/unit/test_sim_cells.c`.
Tests: truth tables of every bit gate; constants; `$sop` ON-set, OFF-set (Review Focus 3), `-` literals, zero-input; `$_DFF_P_/N_` update only on their edge; `$_FF_` on posedge; `$_DLATCH_P_/N_` transparency; INIT 0/1/2/3 → initial state 0/1/0/0.

### Task 2: Build: flatten and levelize
**Files:** Create `src/sim/sim.h`, `src/sim/build.c`, `src/sim/levelize.c`, `tests/unit/test_sim_build.c`.
**Produces:** `odin3_status odin3_sim_build(odin3_design *design, odin3_module_id top, odin3_sim **out)`, `void odin3_sim_destroy(odin3_sim *sim)`; instance expansion via an explicit worklist; nets → value slots; clock discovery (nets on latch clock/enable pins must be primary inputs — Review Focus 4); levelized combinational order; loop detection naming a net (Review Focus 2); black boxes without a `simulate` hook → located error naming the type. Tests: two-level hierarchy flattens to the same results as its flat equivalent; loop; clock from logic; unsupported black box; OOM sweep.

### Task 3: Cycle engine, API and vector driver
**Files:** Create `src/sim/eval.c`, `src/sim/prng.{h,c}`, `tools/sim-check/odin3-sim-vectors.c` (CMake target), `tests/unit/test_sim_cycle.c`.
**Produces:** `odin3_sim_set_input`, `odin3_sim_cycle`, `odin3_sim_get_output` (port index + bit), `odin3_sim_input_count/output_count` and names; the driver `odin3-sim-vectors in.blif --seed S --cycles N [--techlib L]` printing `cycle <inputs> <outputs>` per line (binary, port order, clock inputs excluded from inputs and toggled internally). Tests: Review Focus 1; a counter; a 2-stage pipeline; determinism for a seed; one golden fixture per oracle simulated for 64 cycles without error.

### Task 4: Word cells and tech-library hard cells
**Files:** Modify `src/ir/cells/{logic,arith,compare,mux,reduce}.c` (hooks, bit-blasted, signedness from parameters), `src/techlib/` (an `fn` interpreter over port bit spans: integers up to 64 bits fast path, wider via a small little-endian limb array for `+ - * & | ^ ~ << >> ==`), `tests/unit/test_sim_word.c`.
Tests: every word cell for widths 1, 7, 64, 65 and mixed signedness; `adder` and `multiply` from `lib/vtr.o3lib` incl. 36×36 → 72 (Review Focus 5) against a reference big-integer computation in the test.

### Task 5: Reference harness and the golden run
**Files:** Create `tools/sim-check/sim-check` (bash), `tools/sim-check/models/adder.v`, `tools/sim-check/models/multiply.v`, `tools/sim-check/tb.sh` (testbench generator); Modify `CMakeLists.txt` (CTest `sim_check_fixtures`), `docs/PHASE1.md` (results).
Per spec "Reference and comparison": pure-logic goldens via ABC → Verilog; adder/multiply goldens via Yosys `read_blif -wideports; write_verilog -noattr` + models; RAM and implicit-black-box goldens excluded and listed; seeds 1–3, 64 cycles; compare line by line; `-j` ≤ 2; record pass/fail/excluded counts, slowest file, peak RSS in `docs/PHASE1.md` verbatim from the run; every mismatch investigated (reduce to a fixture; fix our simulator, or document a reference-tool limitation with evidence).
