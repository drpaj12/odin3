# 5.1 `lpmmap` (Altera via LPM, light) Implementation Plan (v1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

v1 (2026-10-19). The spec `docs/specs/2026-10-19-5.1-lpm-design.md` is **not yet approved**. Code
waits for Peter's approval of its mapping rules (CLAUDE.md rule 10, DESIGN §12). Its rule IDs
(L, P, A, M, C, R, S, W, H, F, T, V) are binding here once approved. Choices the spec leaves
open are agent defaults, listed under "Spec points made exact" and logged in PHASE5 by Task 10.
Task 1 (the name verification) may start before approval: it is documentation only.

**Goal:** a pass `lpmmap` and a tech library `lib/lpm.o3lib` so that a design's word-level `$add`,
`$sub`, `$mul`, comparisons and inferred `$mem` become `lpm_add_sub`, `lpm_mult`, `lpm_compare`
and `altsyncram` instances with translated parameters, everything else stays soft, the existing
Verilog writer prints them as module instances with `#(.P(value))`, and `read_techlib` plus
`read_verilog` read them back as the registered cell types. `--family` sets
`intended_device_family` (default `"Cyclone V"`).

**Architecture:** `src/passes/lpmmap/`. A driver visits modules and cells in node-ID order
(`$add`/`$sub`, `$mul`, comparisons, `$mem`, spec P-4). Each source cell is one transaction (build
all nodes and nets first, then reserve, delete the source and merge its output nets, so `NO_MEMORY`
leaves the source intact, spec H-8). One provenance operation and one DERIVED record per source
cell (H-6). A small kit `lm_kit.[ch]` mirrors the shape of `hm_kit` (3C) but is not tied to the four
VTR types (spec P-1). Evidence: Unity rule tests on hand-built IR (exact pins and parameters),
five micros through the CLI, a write/read/write fixpoint test and Verilog lint. No simulation
model, no equivalence (PHASE5 decision 1).

**Tech stack:** C17, `src/util`, `src/ir` (no change), `src/techlib` (one reader change, Task 2),
`src/passes/budget.[ch]`, `odin3_opt_both_signed` (`src/passes/opt/kit.h`, pure), Unity; Python 3
stdlib (the micro driver); iverilog and Verilator (lint, both at `/usr/bin` here).

**Spec:** `docs/specs/2026-10-19-5.1-lpm-design.md` v1. Also `docs/IR.md` (IR-7b, IR-8/9,
IR-12/13), the 1G spec and `src/techlib/reader_cell.c`, the 3C spec/plan and `src/passes/hardmap/`
(read only: the transaction pattern), `src/backends/verilog/writer.h`,
`src/frontends/verilog/read_verilog_lib.c`, the 2D spec §3.1a and EL-6 item 5.

## Global Constraints

- **Code standard** (CLAUDE.md): C17, `-Werror`, lizard <= 15 CCN / 60 lines / 5 parameters, no
  VLA, no recursion, only `cleanup:`, named constants, `src/util` containers, no `NOLINT`.
- **Names:** every port and parameter name in `lib/lpm.o3lib` and in the rule code comes from the
  spec's tables, each with its `file:line` or its V item. A name with no source is not coded; the
  task stops (see Task 1). `lpm_compare` has no local source at all.
- **IR discipline:** build before the first destructive step; `NO_MEMORY` leaves the IR valid and
  the source cell intact; names are never dropped (IR-2); no compaction; `processes = REFUSE`;
  every IR-building test runs `odin3_check_design` FULL; `check` runs before and after in Debug.
- **Library lookup:** types found by name, never created; a missing or non-`blackbox` type is the
  located error of spec P-2.
- **Determinism:** node-ID order; two runs give byte-identical Verilog.
- **Diagnostics:** the spec's §13 texts verbatim; tests assert whole lines through a capturing sink.
- **Builds:** `tools/build-locked --preset debug -j6 && ctest --preset debug -j4`. No build while
  a heavy run holds the lock. Nothing in 5.1 uses `tools/heavy-run`.
- **No code in `~/odin3-ws/external`.** The Yosys and VTR files are read only.
- `/lint` (`tools/lint.sh`) before each commit; commit and push at each green checkpoint, and
  after each rule (memory: WSL updates have killed work).
- The script of spec P-3: `read_techlib lib/lpm.o3lib; read_verilog D.v; proc; opt; wreduce;
  opt_clean; opt -full; lpmmap; opt -full; write_verilog out.v`. Task 9 keeps it in one file,
  `tests/lpm/lpm.script`.

## Review Focus

Failure modes the spec implies but its rules do not pin; each test is added to the owning task.

1. **Degenerate widths** (`Y_WIDTH` 0, an operand of width 0, `ABITS` 0 after `wreduce`, `Y_WIDTH`
   above the product). Expected: left alone or soft with the spec's WARN, never a crash or an
   out-of-range pin. Tasks 5, 6, 7, 8.
2. **Aliased operands and results** (`a + a`, `a - a`, a repeated sign bit in `ext`, a `Y` bit
   that is also an output port, a comparison whose `Y` is wider than 1). Expected: a clean `check`
   and the correct nets. Tasks 5, 7.
3. **Idempotence and explicit LPM instances** (`lpmmap` run twice; a design that already
   instantiates `lpm_add_sub` or `altsyncram` through `read_verilog`). Expected: the second run
   maps nothing, an explicit instance is untouched. Tasks 5, 8.
4. **A `$mem` that stays soft keeps its flip-flops** (R-1 merge is part of the transaction).
   Expected: after a soft verdict the `$dff` cells are intact. Task 8.
5. **Stub versus registered type on read-back** (spec W-3): the file's own `(* blackbox *)` stubs
   and the registered library type must agree. Expected: the read-back IR holds the registered
   type with the written parameters. Task 9.
6. **Parameter kinds on read-back** (INT versus STRING, strings with spaces such as `"Cyclone V"`
   and `"MAX 10 FPGA"`). Expected: byte-exact through write and read. Tasks 2, 9.

## Spec points made exact here (agent defaults, reversible; Task 10 logs them in PHASE5)

- (a) **Pass name and entry:** `lpmmap`; `odin3_status odin3_lpmmap_run(odin3_pass_ctx *ctx,
  odin3_design *design, const odin3_lpmmap_opts *opts, odin3_lpmmap_stats *stats)` in
  `src/passes/lpmmap/lpmmap.h`; `odin3_lpmmap_opts { const char *family; }` (NULL means
  `"Cyclone V"`); stats `{ add_sub, mult, compare, ram, soft }` feed the H-8 INFO line.
- (b) **Attribute** `lpmmap` = `<type>:<role>` with roles `add`, `sub`, `mul`, `cmp`, `sp`, `sdp`
  (spec H-6).
- (c) **Library file name and library name:** `lib/lpm.o3lib`, `library lpm`.
- (d) **Representation spellings** `"SIGNED"` and `"UNSIGNED"`, `lpm_direction` `"ADD"`/`"SUB"`:
  provisional, replaced by Task 1's verified values. A task that finds a verified spelling
  different from the spec updates the spec in the same commit.
- (e) **`ABITS` 0** maps with `widthad_a = 1` and the address tied to gnd.
- (f) **A `$mem` with `SIZE` below `2^ABITS`** maps with `numwords_a = SIZE`.
- (g) **Test dir** `tests/lpm/` (micros, the script file, expected instance counts in
  `tests/lpm/expect.txt`).
- (h) **Lint gate** is `iverilog -g2005 -Wall` (required, exit 77 when absent) with Verilator as an
  extra leg when installed.
