# Odin III 1.5.1 release notes

Status: ready to tag (`v1.5.1`; the tag is the owner's). Built from `origin/main` `347a3d73` plus the release PR.

## What it is

A patch release on v1.5.0. The C ABI stays 7, no output changes. Purpose: Odin III O2 (provenance to HDL) must scale
to real CPUs; Heimdall needs `--prov` runs of OpenCores designs. Found on a-z80-modified (Mimir variant, 2016 LUTs,
365 FFs).

| Change | PR (merge) | Measure on a-z80-modified |
|---|---|---|
| `odin3-prov-steps` streams the `luts` step | #407 (`1ea92f0e`) | peak RSS over 10 GB (OOM) to 340 MB; 8 min 20 s |
| `write_blif --prov-map` labels each distinct anchor list once | #408 (`347a3d73`) | 1423 s to 64 s; RSS 637 MB |

Both fixes keep their outputs byte identical (the name map and BLIF by `cmp`; the step files by tree diff on two maps).

## Notes
- The `luts` step file of that design is 3.3 GB: each object links the constructs of its whole chain (about 24,000 of
  30,672 on average). A cap or a coarser link is a later decision.
- `write_blif --prov-map` compares the join sets of a record and its data parent by count and a 64-bit chain hash.
