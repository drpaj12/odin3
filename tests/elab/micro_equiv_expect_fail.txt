# 2D-8 (fix/multiport-mem): two always blocks that write one memory at the same address in the same
# cycle. 2D emits a v1 `$mem` (the later block's port wins, WR_PRIORITY_MASK 4'0100 once Yosys reads
# it); Yosys 0.55's read_verilog gives the two ports no priority (mask 4'0000, memory_map takes its own
# last port) and iverilog takes the first block. A race by IEEE 1364-2005 11; counterexample addr1 ==
# addr2 with different data (spec 17 #66). Parmys wires both ports of one dual_port_ram, no priority.
