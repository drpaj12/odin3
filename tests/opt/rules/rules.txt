# tests/opt/rules/rules.txt: the per-rule goldens of the opt sub-passes (2F spec 20.1; plan Task 16).
#
#   <sub>/<rule> <counter> <yosys id> [pending|dev=N]
#
# <sub>/<rule> names <rule>.v (or <rule>.blif for the bit gates) and its golden <rule>.il. <counter>
# is an `--opt-stats` name (`const_and`, `opt_dff.d_eq_q`) or, for the passes without rule counters,
# an INFO count (`merge.removed`, `muxtree.ports`, `reduce.changes`, `share.merged`, `clean.cells`,
# `clean.wires`). <yosys id> is the `opt.opt_expr.*` cover point (Yosys 0.55 has cover points in
# opt_expr only) or `log:<regex>` for a line of Yosys's log (run under `debug`). `dev=N` is spec 17
# row N. Run: tools/opt-check/opt-rules --odin3 O [--yosys Y] tests/opt/rules/<sub>.
#
# Reachable only from RTLIL, not from Verilog or BLIF through `proc --noopt` plus at most a
# `// prepass:` of opt_expr/opt_dff; the unit data cases of tests/unit/data/opt/ cover them against
# Yosys 0.55 (the .expect files record the commands):
#   expr:  gate_xor (xor_buffer fires first on every $_XOR_ with a constant), const.$eq and $ne
#          (eqneq.isneq, .empty and .resize fire first), const.$shl $shr $sshr $shiftx (constshift
#          fires first), tribuf_en1 and tribuf_en0 (no Verilog or BLIF construct makes $tribuf)
#   muxtree: a dead $pmux port (Odin III's proc makes the muxes of the tests/unit cases)
#   dff:   always_active_set, ad_eq_q, clr_set_to_arst, const_bit_x, const_bit_z
