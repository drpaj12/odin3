# What hardmap-diff may report for a design other than identical or equivalent (3C spec 9.3, 10).
# Syntax: `<path> <id> <reason>`; <path> is relative to tests/micro/verilog (a micro) or
# benchmarks/verilog (a VTR design). <id> is one of
#   D<n>           the design differs from Parmys by the divergence of spec 10 (equiv-check: not
#                  equivalent), with the same hard-block counts;
#   counts:<+N|-N> <unit>   the unit's count differs from Parmys by exactly N (the netlists are
#                  then not compared); the reason names the divergence;
#   lower-gap      Odin III stops in `lower`, which has no rule for a cell yet (3B-2);
#   unproven       equiv-check cannot decide the design (tests/exit/vtr_unproven.txt).
# A reason is required on every line. An entry that no longer occurs is stale and fails: the list
# shrinks. A `run wreduce first` warning is never listable.

# D15 (new, 2026-10-17): Parmys's Yosys (opt_mem) deletes a memory that has no write port and no
# INIT; its read data is x and the golden netlist has no RAM and undriven outputs. Odin III's opt
# has no opt_mem, so hardmap maps the read-only memory to RAM slices with we on gnd (R-10 p_1_0).
# Not a hardmap rule: the fix is an opt_mem rule in 3G. Checked by hand: the golden BLIFs have no
# subckt at all and Odin III's slices carry data and we on gnd, so no defined value differs.
common/1r.v counts:+8 single_port_ram D15: read-only memory without INIT, Parmys deletes it (opt_mem), Odin III maps 8 slices
common/2r.v counts:+8 dual_port_ram D15: read-only memory without INIT, Parmys deletes it (opt_mem), Odin III maps 8 slices
