# The reviewed eq-x record of the VTR benchmarks (decision 13): a design whose equivalence to Parmys
# holds only outside the x-cones (equiv-check --x-report exit 3) passes only when it is recorded here
# with EXACTLY the outputs equiv-check excluded. Syntax:
#   design <path relative to benchmarks/verilog> <count> <sha256 of the sorted output names> <reason>
#   bus <path> <output name without its [index]> <count>      (the counts add up to <count>)
# exit-check compares the observed outputs (count, hash and per-bus counts) with the record: an
# eq-x design that is not recorded, one whose excluded outputs differ, a record whose design now
# passes (XPASS) and a record that names no design (stale) all fail the run. Every excluded output is
# also written to <work>/<NNNN-design>/x-cones.txt for the review.
#
# A record needs a REASON that explains why the excluded outputs are x. "x" here is Parmys's `unconn`
# net (a constant 0 to ABC). The cone is removed whole, so it also hides any real difference behind
# it: a design is recorded only when the review shows that every difference inside the cone is the
# resolution of an `unconn` and nothing else (an uninitialised RAM word, an unconnected input).
#
# stereovision0 is recorded (2H eq-x review, 2026-10-14): Odin III's RTLIL is dsec-equivalent to Yosys's own
# elaboration of the whole design, and with `wreduce` removed from the shared script the spliced netlist is
# fully equivalent to Parmys's (no x-cone at all). The 141 outputs are downstream of Parmys's `unconn`
# padding of signed adders (Parmys ignores A_SIGNED/B_SIGNED and pads the shorter operand with unconn = 0
# instead of its sign bit), applied to different adders because wreduce's signed rewrite depends on cell
# order. Both netlists are IEEE-wrong there (a Parmys defect, see 2H-splice-report.md section 17).
#
# arm_core is recorded (2H arm_core review, 2026-10-14): it is fully equivalent, and its eq-x is the
# x-report's coarse cone on top of a guessed black-box pairing. Every one of its 1192 Parmys RAM slices has
# `unconn` address pads addr[8..14] (the arch's 15-bit address tie-off, the same on both sides), so the cone
# holds every RAM pin and everything fed by a RAM read (19931 outputs, 3070 buses below; the `?anonN`
# names are equiv-check's file-order labels for unnamed boxes). Parmys writes no RAM names, so
# --match-unnamed guessed all 1192 pairs (it cannot tell the four cache ways apart by simulation): the
# guessed check says NOT equivalent, the cone hides it. With every slice named by its memory and bit
# (memory found from its write-enable net, bit from MEM~N-<bit>), the golden and the splice are
# `equivalent (abc dsec)` with no x-cone. Odin III's RTLIL equals Yosys's elaboration in all 19 modules,
# and the pre-Parmys RTLIL and Parmys's logic lowering (RAMs cut) are equivalent too (report, "arm_core").
